# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Orino.js, please report it responsibly by contacting the maintainer directly at [ajaysaagar.dev@gmail.com](mailto:ajaysaagar.dev@gmail.com) or creating a GitHub Security Advisory.
