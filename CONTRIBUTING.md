# Contributing to Orino.js

Thank you for your interest in contributing to Orino.js!

## Development Workflow

1. Fork the repository and create your branch from `main`:
   ```bash
   git checkout -b feat/my-new-feature
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Make your changes and run the test suite:
   ```bash
   npm test
   ```
4. Commit your changes using conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`, `test: ...`).
5. Push to your branch and submit a Pull Request.

## Code Style

- Write clean, readable code with TypeScript/JavaScript.
- Add unit tests for any new functionality or bug fixes.
- Ensure all CI tests pass prior to review.
